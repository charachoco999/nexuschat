# Instalar Nexus Desktop 0.9.0-alpha.3

1. Descarga `Nexus-Desktop-Setup-0.9.0-alpha.3.exe` desde el Release oficial o desde el artefacto de GitHub Actions.
2. Ejecuta el instalador. Se instala en tu perfil de usuario.
3. Abre Nexus Desktop desde el menú Inicio.

Esta Alpha 3 es la primera versión que incorpora el actualizador. Si tienes instalada Alpha 2, debes instalar Alpha 3 manualmente una sola vez. Después recibirás las actualizaciones desde el propio Nexus Desktop.

El instalador incluye el bootstrapper de WebView2 y lo instala si el runtime falta. Necesitarás conexión a Internet durante la instalación en ese caso.

No necesitas Node.js, Rust, Cargo, Visual Studio ni NSIS para ejecutar Nexus.
