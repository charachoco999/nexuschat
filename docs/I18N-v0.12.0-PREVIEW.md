# Nexus · localización v0.12.0

## Alcance de esta actualización

Esta actualización amplía la localización del cliente web existente. El español es el idioma fuente y se ofrecen 14 destinos: inglés, esloveno, italiano, francés, japonés, chino simplificado, alemán, portugués, guaraní (beta), catalán, gallego, euskera, latín (beta) y la variante española lúdica Julio Verne.

El catálogo se divide en el runtime `assets/i18n/i18n.js` y el catálogo ampliado `assets/i18n/catalog-extra-v0.12.js`. El segundo se carga después del runtime y antes de `assets/js/app.js`.

## Resultado de la auditoría

- 885 claves fuente únicas.
- 14 idiomas de destino.
- 12.390 traducciones esperadas.
- 0 traducciones ausentes en el catálogo.
- La auditoría estática de HTML y los puntos de inserción de texto de JavaScript ya no detecta frases normales de la interfaz pendientes de traducción. Los valores que siguen sin traducirse deliberadamente son nombres de marca o funciones, nombres de fuentes, sintaxis de ejemplo, fragmentos de código y valores demostrativos como correos o nombres de canal.

Este control no sustituye una revisión visual completa: algunos textos se forman dinámicamente a partir de datos de usuario o del servidor y deben probarse en funcionamiento.

## Reglas de localización

- Usa `NexusI18n.t(clave, variables)` para textos dinámicos.
- Para HTML, utiliza `data-i18n`, `data-i18n-placeholder`, `data-i18n-title`, `data-i18n-aria-label`, `data-i18n-alt` y `data-i18n-value`.
- No traduzcas mensajes escritos por usuarios, biografías, nombres o estados personalizados, código, ejemplos de sintaxis, URLs ni archivos adjuntos.
- Guaraní y latín permanecen en beta hasta recibir revisión lingüística competente.
- La variante Julio Verne es lúdica y no debe usarse como traducción técnica.
- La versión española de los Términos y Condiciones sigue siendo la fuente jurídica de referencia. Los avisos y controles de actualización se traducen, pero las demás versiones de los términos no deben considerarse textos jurídicos oficiales sin revisión competente.

## Instalación

1. Haz una copia de seguridad de la web.
2. Copia los archivos del ZIP a las mismas rutas del directorio raíz de Nexus, sustituyendo los archivos existentes.
3. Conserva tu `assets/js/config.js`: no está incluido en el ZIP y no debe reemplazarse.
4. No se necesita una migración de Supabase para esta actualización de idioma.
5. Haz una recarga forzada del navegador para limpiar la caché.

## Verificación

Ejecuta `node scripts/check-i18n.mjs` desde una copia local del repositorio. El workflow de GitHub Actions ejecuta el mismo comprobador y empaqueta esta actualización como artefacto descargable.

Queda pendiente la revisión visual manual de todas las pantallas en escritorio y móvil, además de la revisión lingüística experta de los dos idiomas beta y cualquier revisión jurídica de textos legales traducidos.
