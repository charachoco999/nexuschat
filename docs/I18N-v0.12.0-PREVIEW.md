# Nexus v0.12.0 localization preview

This update extends the existing v0.11.1-alpha2 language selector to a complete static-UI catalogue for the current release. It adds a local translation catalogue, cache-busted script references, updated release notes, and an automated catalogue/static-string check.

The 14 additional variants are English, Slovenian, Italian, French, Japanese, Simplified Chinese, German, European Portuguese, Guarani (beta), Catalan, Galician, Basque, Latin (beta), and the playful Jules Verne Spanish variant.

User-created content remains untouched. The authoritative legal document remains in Spanish pending separate legal review.
