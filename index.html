Guía de Markdown de Nexus

Formato básico

**negrita** · *cursiva* · ~~tachado~~ · `código`

> cita · [texto](https://ejemplo.com)

Bloques de código

```js
const nexus = true;
```

Escribe el identificador del lenguaje después de las tres comillas invertidas para activar el coloreado.

Markdown personalizado

{red:Texto rojo}

{color:#ff8800:Texto naranja}

{size:24:Texto de 24 píxeles}

{font:serif:Texto serif}

{glow:blue:Texto azul brillante}

Los colores, tamaños y fuentes están limitados a valores seguros. No se admite HTML arbitrario ni CSS libre.
